# Repositório da Trilha DevOps

Este repositório foi criado para centralizar os estudos, documentos, exercícios, laboratórios e entregáveis desenvolvidos durante a trilha de aprendizagem em DevOps.

O objetivo é manter o conteúdo organizado por módulos, facilitando a consulta, a revisão dos estudos e o acompanhamento da evolução ao longo da trilha.

## Estrutura do repositório

```text
README.md
modulo-1-redes/
modulo-2-linux-git/
modulo-3-shell-scripting/
modulo-4-apis-nginx/
modulo-5-devops/
modulo-6-iac/
scripts/
docs/
labs/
```

## Organização dos módulos

### Módulo 1 — Redes

A pasta `modulo-1-redes` contém materiais relacionados a:

* conceitos básicos de redes;
* endereçamento IP;
* DNS;
* protocolos HTTP e HTTPS;
* testes de conectividade;
* ferramentas de diagnóstico de rede;
* resolução de problemas de comunicação.

### Módulo 2 — Linux e Git

A pasta `modulo-2-linux-git` contém materiais relacionados a:

* comandos básicos do Linux;
* navegação e manipulação de arquivos;
* usuários, grupos e permissões;
* processos e serviços;
* leitura e análise de logs;
* uso do Git;
* branches, commits, push, pull e pull requests;
* resolução de conflitos.

### Módulo 3 — Shell Scripting

A pasta `modulo-3-shell-scripting` contém:

* scripts Bash;
* automações simples;
* validação de parâmetros;
* monitoramento de disco, memória e CPU;
* verificação de serviços;
* geração de relatórios;
* backups automatizados.

### Módulo 4 — APIs e Nginx

A pasta `modulo-4-apis-nginx` contém materiais relacionados a:

* funcionamento de APIs;
* métodos HTTP;
* requisições GET e POST;
* uso de headers;
* testes com `curl`;
* testes com Postman;
* instalação e configuração do Nginx;
* proxy reverso;
* análise de logs de acesso e erro.

### Módulo 5 — DevOps

A pasta `modulo-5-devops` contém materiais relacionados a:

* conceitos e cultura DevOps;
* integração entre desenvolvimento e operações;
* automação;
* integração contínua;
* entrega contínua;
* GitHub Actions;
* monitoramento;
* logs e evidências;
* segurança e Dependabot.

### Módulo 6 — Infraestrutura como Código

A pasta `modulo-6-iac` contém materiais relacionados a:

* conceitos de Infraestrutura como Código;
* criação automatizada de ambientes;
* versionamento de infraestrutura;
* ferramentas de IaC;
* arquivos de configuração;
* exemplos e laboratórios práticos.

## Pastas adicionais

### `scripts`

Armazena scripts reutilizáveis desenvolvidos durante a trilha.

Exemplos:

* verificação de uso de disco;
* verificação de memória;
* verificação de CPU;
* monitoramento de serviços;
* backup de diretórios;
* análise de logs;
* geração de relatórios.

### `docs`

Armazena documentos gerais que podem ser utilizados em diferentes módulos.

Exemplos:

* guias de comandos;
* checklists;
* documentações técnicas;
* anotações;
* procedimentos;
* relatórios.

### `labs`

Armazena laboratórios práticos e simulações.

Exemplos:

* testes de comunicação web;
* análise de logs;
* configuração de serviços;
* testes com APIs;
* automações;
* cenários de diagnóstico.

## Objetivo final

Ao final da trilha, este repositório deverá apresentar evidências dos conhecimentos adquiridos, incluindo documentos, scripts, laboratórios, automações e exemplos práticos relacionados à operação de sistemas e às práticas de DevOps.
